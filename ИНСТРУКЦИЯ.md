# SCP Foundation — инструкция по работе с проектом

Настольное приложение на **Java + JavaFX** для учёта аномальных объектов Фонда SCP.
Работает с двумя СУБД на выбор — **PostgreSQL** или **Firebird**. Обе скачиваются
портативно в папку `db-runtime/` внутри проекта, системная установка СУБД не нужна.

---

## 1. Что нужно заранее

| ОС | Требования |
|---|---|
| **Windows 10/11** | JDK 17+ в `PATH`, Git. `curl` и PowerShell уже есть в системе |
| **Linux (x64)** | JDK 17+, Git, `curl`, `tar`, `unzip`, `xz` (`sudo apt install curl unzip xz-utils`) |
| **macOS (Intel и Apple Silicon)** | JDK 17+, Git, `xz` (`brew install xz`). Firebird на macOS не ставится автоматически — работает только PostgreSQL |

JDK можно взять, например, на <https://adoptium.net> (Temurin 21 LTS). Проверка: `java -version`.

При первом запуске нужен интернет: скачиваются ~6 JAR, PostgreSQL (~25 МБ) и Firebird (~15 МБ).
Maven/Gradle не используются, сборка идёт прямо через `javac`.

## 2. Быстрый старт

```bash
git clone https://github.com/walterwar92/scp-foundation-tracking.git
```

```bash
cd scp-foundation-tracking
```

**Windows:**

```bash
start.bat
```

**Linux / macOS:**

```bash
./start.sh
```

Скрипт выполняет 5 шагов, каждый можно перезапускать безопасно:

1. **setup** — качает зависимости в `lib/` (JDBC-драйверы PostgreSQL и Jaybird, JavaFX 21 под вашу ОС).
2. **db-setup** — качает портативные PostgreSQL 16 и Firebird 5, запускает их,
   создаёт БД и накатывает `sql/<субд>/01_schema → 02_constraints → 03_seed`.
3. **Выбор СУБД** — `1` PostgreSQL (по умолчанию) или `2` Firebird; записывает `config.properties`.
4. **build** — компилирует `src/` в `out/` и копирует `resources/`.
5. **run** — открывает окно приложения.

Повторный запуск быстрый: загрузки и заливка данных пропускаются.

## 4. Повседневная работа

| Действие | Windows | Linux / macOS |
|---|---|---|
| Всё сразу (БД + сборка + запуск) | `start.bat` | `./start.sh` |
| Запустить серверы БД | `db-start.bat` | `./db-start.sh` |
| Остановить серверы БД | `db-stop.bat` | `./db-stop.sh` |
| Пересобрать после правок кода | `build.bat` | `./build.sh` |
| Запустить без пересборки | `run.bat` | `./run.sh` |

Цикл разработки: правка в `src/` или `resources/` → `build` → `run`.
После перезагрузки компьютера серверы БД сами не поднимаются — запустите `db-start` или `start`.

## 5. Подключение к БД

Текущая конфигурация — `config.properties` (создаётся скриптами, в git не попадает;
шаблон — `config.example.properties`).

| | PostgreSQL | Firebird |
|---|---|---|
| Хост:порт | `localhost:5433` | `localhost:3051` |
| БД | `scp_foundation` | на Windows `C:/Users/Public/scp-foundation-fdb/scp_foundation.fdb`, на Linux алиас `scp` |
| Пользователь / пароль | `scp_admin` / `scp-foundation-db` | `SYSDBA` / `masterkey` |

Порты нестандартные (5433 и 3051), чтобы не конфликтовать с уже установленными СУБД.
Чтобы сменить СУБД, перезапустите `start` и выберите другой пункт, либо отредактируйте
`config.properties` и запустите `run`.

Посмотреть данные вручную удобно через DBeaver (поддерживает обе СУБД) с параметрами из таблицы.

## 6. Структура проекта

```
src/ru/scp/foundation/
  Main.java            точка входа JavaFX
  config/              чтение config.properties
  db/                  ConnectionManager, SqlDialect (различия Postgres/Firebird)
  model/               record-классы сущностей
  dao/                 DAO на каждую таблицу (JDBC, PreparedStatement)
  auth/                вход, SHA-256 + соль, сессия
  access/              правила доступа по допуску
  ui/controllers/      контроллеры экранов
  ui/util, animation/  ячейки таблиц, диалоги, анимации
  util/                i18n, SqlRunner (накат SQL), TxzExtractor (распаковка Postgres на Windows)
resources/
  fxml/                разметка экранов
  css/scp.css          оформление
  i18n/                messages(_ru).properties — EN/RU интерфейс
sql/postgres, sql/firebird/
  01_schema.sql        таблицы
  02_constraints.sql   FK, CHECK, UNIQUE
  03_seed.sql          тестовые данные (≥5 записей на таблицу)
docs/
  superpowers/         проектная спецификация и план реализации
  testing-plan.md      чек-лист ручного тестирования
```

**Таблицы:** `scp_objects`, `containment_sites`, `containment_history`, `personnel`,
`mtf_teams`, `mtf_members`, `incidents`, `procedure_revisions`, `users`.

## 7. Как вносить изменения

- **Новое поле или таблица** — правьте SQL **в обеих** папках (`sql/postgres` и `sql/firebird`),
  затем `model/` → `dao/` → контроллер + FXML. Различия диалектов — в `db/SqlDialect.java`.
  В Firebird слова `POSITION`, `ROLE` и т.п. зарезервированы: используйте `dialect().quoteIdent(...)`
  и не давайте колонкам такие псевдонимы через `AS`.
- **Тексты интерфейса** — `resources/i18n/messages.properties` и `messages_ru.properties`.
- **Пересоздать БД с нуля** (после правки SQL):
  1. остановить серверы (`db-stop`);
  2. удалить `db-runtime/.postgres-seeded` и `db-runtime/postgres/data` — для Postgres;
     `db-runtime/.firebird-seeded` и файл `.fdb` (см. таблицу в разделе 5) — для Firebird;
  3. снова запустить `start` или `db-setup`.
- **Хеш пароля для нового пользователя** (после `build`):
  ```bash
  java -cp out ru.scp.foundation.auth.PasswordHasher <login> <пароль>
  ```
  Или проще — через экран Users под `admin`.

## 8. Частые проблемы

| Симптом | Что делать |
|---|---|
| `java not found` / `java не найдена` | установить JDK 17+ и открыть новый терминал |
| `ERROR: run setup.bat first` / `запустите ./setup.sh` | нет `lib/` — запустить `start` или `setup` |
| `ERROR: run build.bat first` / `сначала ./build.sh` | нет скомпилированных классов — `build` |
| «Ошибка подключения к БД» при запуске | серверы не запущены — `db-start`; проверить `config.properties` |
| `Permission denied` при `./start.sh` | `chmod +x *.sh` |
| Зависает на «Старт PostgreSQL на порту 5433…», в выводе `pg_ctl: возможно, уже работает другой сервер` | прошлый запуск прервали Ctrl+C, и «осиротевший» процесс postgres держит порт. Закрыть окно; Windows: `Get-Process postgres \| ? Path -like '*scp-foundation*' \| Stop-Process -Force` в PowerShell; Linux/macOS: `pkill -f db-runtime/postgres`. Затем снова `start` |
| Порт 5433/3051 занят | `db-stop`, либо завершить чужой процесс на этом порту |
| macOS: выбор Firebird не работает | ожидаемо — на macOS автоматически ставится только PostgreSQL |
| Кракозябры в консоли Windows | это кодировка cmd; на работу приложения не влияет |

Не прерывайте `start` через Ctrl+C во время запуска БД; останавливайте серверы через `db-stop`.
