# Промт для Claude Design

> **Как использовать:** скопируйте весь блок ниже (от «Создай мокапы…» до конца) и вставьте в claude.ai/design. Полученные HTML/CSS-мокапы используются как референс при переносе в JavaFX FXML и CSS-файл `resources/css/scp.css`.

---

Создай мокапы интерфейса для приложения «Система учёта аномальных объектов Фонда SCP». Это вымышленная организация из вселенной SCP Foundation, занимающаяся содержанием аномальных объектов. Интерфейс должен выглядеть как **внутренний терминал секретной организации** — что-то среднее между программами ФБР/ЦРУ в шпионских триллерах и хакерским терминалом из киберпанк-фильмов. Эстетика «meta-universe Foundation software».

## Визуальная стилистика

**Цветовая палитра:**
- Основной фон: глубокий чёрный `#0a0a0a` с тонкой структурой (лёгкий шум или сетка).
- Поверхности (карточки, панели): чёрный с примесью серого `#141414`.
- Акцент 1 (основной): оранжевый SCP `#FF6B35`. Используется для границ, заголовков, основного текста на тёмных кнопках.
- Акцент 2 (опасность / критичные действия): красный `#C8102E`.
- Основной текст: светло-серый `#e0e0e0`. Второстепенный: `#888`.

**Типографика:**
- Моноширинный шрифт везде (JetBrains Mono, Share Tech Mono, Consolas) — для «терминального» эффекта.
- Заголовки: 20px bold, цвет `#FF6B35`, ВЕРХНИЙ РЕГИСТР.
- Подзаголовки: 14px bold, цвет `#C8102E`.
- Значения в таблицах: 13px, цвет `#e0e0e0`.

**Эффекты:**
- На фокусе/наведении — оранжевое свечение (`box-shadow: 0 0 10px #FF6B35`).
- Кнопки: прозрачный фон, оранжевая рамка 1px, при hover — заливка оранжевым, текст становится тёмным.
- Активная кнопка (primary) — красная рамка `#C8102E`.
- Опасные кнопки (danger, Delete, LOGOUT) — тёмно-красная рамка + красный текст.

## Анимации (опиши, как они должны вести себя; не реализуй CSS целиком)

1. **Boot-sequence на экране логина.** В левом верхнем углу последовательно появляются строки моноширинным шрифтом цвета `#FF6B35`, каждая через 500мс:
   - `> INITIALIZING SECURE TERMINAL...`
   - `> LOADING CONTAINMENT DATABASE...`
   - `> ESTABLISHING ENCRYPTED LINK...`
   - `> AWAITING CREDENTIALS...`

2. **Вращающийся логотип SCP** в центре login-карточки (160×160 px): три стрелки по кругу (упрощённая стилизация настоящего SCP-логотипа), вращаются по часовой стрелке, бесконечно. Внутри — текст «SCP» большой жирной моноширинкой.

3. **Анимация фона на всех экранах.** Три слоя:
   - Лёгкая сетка 40×40px цвета `rgba(255, 107, 53, 0.06)`.
   - ~80 светящихся частиц цвета `#FF6B35` с альфой 0.25–0.75, медленно плывут в случайных направлениях.
   - Горизонтальная сканлайн цвета `rgba(200, 16, 46, 0.4)` высотой 2px, медленно ползёт сверху вниз и зацикливается. Эффект «помехи на CRT».
   - Прошлые кадры частиц затемняются на 25% — создаёт шлейф.

4. **Переход между экранами** — плавный fade-in новой панели (300мс).

5. **Hover на кнопке** — резкий swap фона с появлением dropshadow-glow.

## Экраны для мокапа

Сделай 10 экранов, каждый — отдельным фреймом/блоком, расположенными в галерее:

### 1. LoginView (900×600)
Центрированная карточка ~500×500 с границей `#FF6B35` (2px) и `box-shadow: 0 0 24px #C8102E` (атмосферное свечение). Карточка имеет полупрозрачный фон `rgba(20, 20, 20, 0.92)`. Внутри сверху вниз:
- Вращающийся SCP-логотип (160×160).
- Заголовок «SECURE TERMINAL» (header-стиль).
- Подзаголовок «ACCESS REQUIRED» (subheader-стиль).
- Поле LOGIN (placeholder моноширинный).
- Поле PASSWORD.
- Кнопка `AUTHENTICATE` шириной 260px, primary (красная рамка).
- В случае ошибки — строка с текстом «ACCESS DENIED — неверные учётные данные» цвета `#ff5555`.

В левом верхнем углу экрана (вне карточки) — анимированный boot-текст.

### 2. MainView (1280×800)
Полноразмерное окно после успешного входа:
- **Слева:** sidebar шириной 220px, фон `#0a0a0a`, правая граница оранжевая. Сверху — заголовок «SCP FOUNDATION» и подзаголовок «SECURE TERMINAL». Затем кнопки разделов (full-width, выровнены влево, 200×34):
  - SCP Objects
  - Containment Sites
  - Personnel
  - MTF Teams
  - Incidents
  - Containment History
  - Procedure Revisions
  - *(separator)*
  - Users *(только для O5; для исследователя — скрыто)*
  - *(spacer)*
  - LOGOUT *(внизу, danger-стиль)*
- **Центр:** динамическая область, на фоне которой работает анимация фона. По центру до выбора раздела — приветствие «WELCOME, DR. ALTO CLEF» (header-стиль).
- **Снизу:** status bar высотой ~32px с двумя надписями:
  - Слева: `USER: admin | Dr. Alto Clef | O5 | CLEARANCE L5`
  - Справа: `DB: POSTGRES`

### 3. ScpListView
Таблица с колонками: Item # (100), Code name (220), Class (100), Discovered (120), Description (400).
Сверху тулбар: заголовок «SCP OBJECTS», spacer, поле Search (280px), кнопки Refresh / Add / Edit / Delete (Delete — danger).
Пример строк: `SCP-173 | The Sculpture | Euclid | 1993-06-12 | Hostile concrete statue...`

### 4. SiteListView
Таблица: Code (120), Location (300), Capacity (100), Security Level (140).
Тулбар: «CONTAINMENT SITES» + Search + Refresh/Add/Edit/Delete.
Примеры: `Site-19 | United States, undisclosed | 80 | 5`.

### 5. PersonnelListView
Таблица: Full name (220), Position (220), Clearance (100), Base site (160).
Тулбар: «PERSONNEL» + Search + CRUD.
Примеры: `Dr. Alto Clef | Senior Researcher | 5 | Site-19`.

### 6. MtfListView
Двухпанельный SplitPane (50/50):
- **Левая панель:** подзаголовок «Teams», таблица команд (Callsign 160, Specialization 280, Base site 120). Пример: `MTF Alpha-1 | Red Right Hand | Site-19`.
- **Правая панель:** подзаголовок «Members», сверху кнопки `Add member` / `Remove` (Remove — danger). Таблица (Personnel 220, Joined 120). Пример: `Dr. Alto Clef | 2020-01-15`.
- Над сплитом тулбар: «MOBILE TASK FORCES» + Refresh/Add team/Edit team/Delete team.

### 7. IncidentListView
Таблица: Occurred (160), SCP (120), Site (120), MTF (140), Severity (80), Description (400).
Тулбар: «INCIDENTS» + Label «From:» + DatePicker + Label «To:» + DatePicker + кнопки Apply/Reset + CRUD.
Примеры: `2023-04-12 03:22 | SCP-173 | Site-19 | MTF Epsilon-11 | 4 | Containment breach...`

### 8. ContainmentHistoryView
Таблица: SCP (120), Site (160), Moved in (140), Moved out (140).
Тулбар: «CONTAINMENT HISTORY» + Label «SCP:» + ComboBox с фильтром + Refresh/Add/Edit/Delete.
В колонке «Moved out» — прочерк, если запись открыта (объект всё ещё там).

### 9. ProcedureRevisionsView
Трёхпанельный SplitPane (30/30/40):
- **Левая:** подзаголовок «SCP», ListView с пунктами «SCP-173 — The Sculpture».
- **Центр:** подзаголовок «Revisions», таблица (# 50, Date 120, Approved 200).
- **Правая:** подзаголовок «Procedure text», большой TextArea read-only с текстом ревизии.
- Тулбар сверху: «PROCEDURE REVISIONS» + Add revision/Edit revision/Delete.

### 10. UserManagementView (только O5)
Таблица: Login (160), Person (240), Role (120), Created (180).
Тулбар: «USERS — O5 ONLY» (заголовок чуть тревожный, можно с лёгким glow) + Refresh + `Add user` + `Delete user` (danger).
Примеры: `admin | Dr. Alto Clef | O5 | 2024-01-15 10:23`.

## Общие требования к мокапам

- Покажи все 10 экранов в одном макете в виде галереи / Figma-frames с подписями.
- Используй единую цветовую палитру и типографику.
- На каждом экране должна просматриваться анимация фона (хотя бы статичный «снимок»).
- Кнопки и поля должны быть в нескольких состояниях: default / hover / focused / disabled.
- Для модальных диалогов (Add/Edit) сделай отдельный мокап одного из них — пример формы добавления SCP с полями: Item #, Code name, Class (dropdown), Discovered (date), Description (textarea) и кнопками OK / CANCEL.

Сделай это атмосферно, в духе шпионских триллеров и SCP-вики. Целевая аудитория — преподаватель курса «Базы данных», который ожидает увидеть «настоящий» инструмент учёта аномальных объектов из вселенной Фонда.
